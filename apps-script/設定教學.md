# 餐廳記帳 App — 雲端同步設定教學（Google Sheet + Drive）

做完這份，App 記的每一筆就會自動存進你自己的一張 Google Sheet，照片存進你的 Google Drive。全程免費、免伺服器，跑在你自己的 Google 帳號。大約 10 分鐘。

---

## 第 1 步：建一張 Google Sheet

1. 電腦開 https://sheets.new （會建一張新試算表）。
2. 幫它改個名，例如「餐廳記帳」。
3. 分頁不用自己整理，程式第一次同步會自動建好「單據」分頁跟欄位標題。

## 第 2 步：貼上收件員程式

1. 在這張 Sheet 上方選單：**擴充功能 → Apps Script**（會開一個新分頁）。
2. 把左邊那個 `Code.gs` 裡原本的內容**全部刪掉**。
3. 打開本資料夾的 `Code.gs`，把裡面**全部內容複製貼上**。
4. 找到最上面這行，把密碼改成你自己的一串字（英數字，別用空格），**記起來**：
   ```
   const TOKEN = '改成你自己的密碼_例如_haohuang2026';
   ```
5. 按上方 💾 **儲存**。

## 第 3 步：部署成網址

1. 右上角 **部署 → 新增部署作業**。
2. 齒輪 ⚙️ 選 **網頁應用程式（Web app）**。
3. 設定：
   - **執行身分**：以我（你的帳號）
   - **誰可以存取**：**所有人（Anyone）**  ← 一定要選這個，App 才連得上
4. 按 **部署**。第一次會跳授權：選你的帳號 →「進階 →（不安全）前往…」→ 允許。（這是你自己的程式，安全。）
5. 完成後會給你一條**網址**，長得像：
   ```
   https://script.google.com/macros/s/AKfy..../exec
   ```
   **複製這條 `/exec` 結尾的網址。**

> 小測試：把網址貼到瀏覽器直接開，應看到 `{"ok":true,"service":"餐廳記帳同步",...}` 就對了。

## 第 4 步：在 App 填上網址 + 密碼

1. 手機開 App → 底部 **設定**。
2. 「雲端同步」那格：
   - 上面貼**網址**（`/exec` 結尾那條）
   - 下面貼**密碼**（就是第 2 步你改的 TOKEN，要一模一樣）
3. 先按 **測試連線** → 顯示「✓ 連線成功」代表通了。
4. 按 **儲存** → App 會開始把之前記的單據往上傳，Sheet 就會一列列出現。

---

## 之後怎麼運作

- 記帳照舊：本機先存，有網路就自動把新單據補傳上 Sheet。
- 沒網也能記，等有網再開 App 會自動補傳。
- 照片會壓縮後上 Drive，Sheet 每列的「照片連結」點了就能看。

## 常見問題

- **測試連線失敗 / 回應看不懂**：多半是第 3 步「誰可以存取」沒選「所有人」，或網址不是 `/exec` 結尾。重新部署一次。
- **改了程式想更新**：Apps Script 要**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不變。
- **換密碼**：Code.gs 的 TOKEN 跟 App 設定頁兩邊一起改成一樣。
- **重複同步不會重覆**：同一張單用 id 對應，第二次同步是更新同一列，不會多出一列。
